How the radar prices a launch

Implied value = TVL × category multiple × momentum × maturity. The multiple is calibrated from this snapshot itself: the median market-cap/TVL of the protocols in the same category whose token already trades. Momentum rewards seven-day TVL growth in a capped band; maturity credits the years a protocol has run with no token. Launched protocols ride the board as anchors at their real market cap, tagged LAUNCHED, so the scale is honest. An implied value is this board's own claim about a launch that may never happen — it is not a prediction that a token will be issued.
